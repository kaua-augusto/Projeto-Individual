# Thanks page photos

Photos for `agradecimentos.html`. Put one file per person here and point the `foto` field of that person in `public/js/agradecimentos.js` to it (`./assets/img/agradecimentos/<file>`).

- A cut-out PNG with a transparent background looks closest to the character on the game's "Play like" screen, because it blends into the dark panel.
- A tall portrait works best: the photo column is taller than it is wide.
- `exemplo.svg` is a placeholder silhouette used by the three example people. Delete it once every person has a real photo.
