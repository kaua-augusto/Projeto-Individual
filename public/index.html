    03 // Por que este projeto

    Este é um projeto individual sobre um interesse pessoal: Cyberpunk 2077 e a estética cyberpunk como um todo — neon, chuva, megacorporações, implantes e muita música eletrônica.

    A ideia é juntar o que eu gosto com o que estou aprendendo: um site com cadastro, login, banco de dados, uma API externa de verdade e uma dashboard que mostra o caminho até os 100%.
